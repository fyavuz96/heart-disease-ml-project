## Heart Disease Prediction Project

This project demonstrates the implementation of linear regression, polynomial regression, Ridge regression, and cross-validation using the Heart Disease dataset. The goal is to build a complete machine learning pipeline and present a well-documented portfolio of work.

### Features

* Polynomial Regression
* Ridge Regression
* Scikit-learn Pipeline
* ​​Scaling with StandardScaler
* Cross-Validation (KFold)
* R² evaluation

### Dataset

```
data/heart.csv
```

The Cleveland Heart Disease dataset on Kaggle can be used.

### Installation

```
pip install -r requirements.txt
python main.py
```
